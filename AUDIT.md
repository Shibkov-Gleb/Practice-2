этап имеет подробное сообщение, а исправления уже включены в коммиты этапов.

Резервная ветка предыдущей истории: `backup/before-stage-fixup-2026-10-30`.

## Проверка PEP 8

Автоматически проверены форматирование, отступы, пустые строки, пробелы,
длина строк, основные правила именования и ошибки импортов. Отдельный
контроль ограничивает строки docstring и комментариев 72 символами.

Дополнительно вручную проверены группировка импортов, публичные и внутренние
интерфейсы, именование констант, сравнения с None, проверки пустых коллекций,
обработка исключений, управление файлами и согласованность возвратов функций.
Имена `setUp` и `assertEqual` сохраняют обязательный интерфейс стандартного unittest.

В модулях приложения объявлен `__all__`. Внутренние функции имеют префикс `_`.
Область `try` при чтении XML ограничена чтением и разбором файла.

Исключено только правило W503: оно запрещает перенос перед бинарным оператором,
который разрешён и рекомендован современным PEP 8. В `.flake8` используется
`ignore = W503`, поэтому другие стандартные исключения Flake8 не скрывают проверки.

У PEP 8 есть рекомендации, требующие человеческой оценки. Отсутствие сообщений
линтера само по себе не считается доказательством соблюдения всего документа;
результат выше включает и ручную проверку применимых рекомендаций.

## Воспроизводимые проверки

```sh
python3 -B -m unittest discover -s tests -q
python3 -B -m tools.check_style
python3 -B -m flake8 src tests tools
sh -n run.sh
make demo-errors demo-graphs
git diff --check
```

Результат текущей версии: **79 тестов успешно**, Flake8 и автономная проверка
завершаются без ошибок. Тесты проходят на Python 3.9.6 и Python 3.12;
на Python 3.12 предупреждения DeprecationWarning считаются ошибками.
Снимки переписанных коммитов проверены во временных каталогах:
**32 теста** первого этапа и **48 тестов** второго этапа проходят.
