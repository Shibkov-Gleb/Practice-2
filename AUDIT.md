## Проверка всего применимого PEP 8

Автоматические проверки: отступы и пробелы, табуляция, пустые строки, длина
строк, переносы, окончания файлов, имена, импорты и типичные ошибки Python.
Docstring и комментарии ограничены 72 символами. Ограничения функций,
сложности и магических чисел проверены отдельно по AST.

Ручная проверка дополняет линтер: группировка стандартных и локальных импортов,
расположение `__all__`, явные публичные интерфейсы, внутренние имена с `_`,
константы, сравнения с None, проверки пустых коллекций, согласованность возвратов,
конкретные типы исключений, небольшие области try и контекстные менеджеры файлов.
В новом коде нет голых except, сравнений с True/False через `==`, глобальных
переменных с изменяемым рабочим состоянием или путей, собираемых shell-командой.
Русские docstring соответствуют языку проекта и задания; UTF-8 используется явно
при работе с файлами и внешним выводом. Обязательные unittest имена `setUp` сохранены.

Настройка `.flake8`: select E,F,W,C90,N, max-line-length 79, max-complexity 10,
ignore только W503. Он конфликтует с современной рекомендацией PEP 8 переносить
бинарный оператор в начало продолжения строки. Другие стандартные исключения
Flake8 не скрывают проверки. Использованы Flake8 7.5.0 и pep8-naming 0.15.1.

PEP 8 содержит контекстные рекомендации, поэтому отсутствие ошибок линтера
не выдаётся за формальное доказательство всех рекомендаций документа.
Итог учитывает ручной просмотр и автоматические проверки применимых правил.

## Границы операций

Модель npm сохранена с этапа 2: вершина соответствует имени, метаданные берутся
из latest. Semver, несколько версий имени и точная установка не моделируются.
Для is-odd это даёт отличие версии is-number от npm при совпадении имён и рёбер.
Ограничения и другие возможные причины расхождений описаны в COMPARISON.md.

Обратный поиск в тестовом режиме использует **весь** репозиторий, включая узлы
вне прямого графа выбранного пакета. В режиме npm он ограничен известным
достижимым графом; глобальный поиск по всему публичному реестру не заявляется.
Область печатается в CLI. Исключённый корень не вызывает HTTP-запросов.

D2/SVG сначала формируются во временном каталоге; ошибка компиляции сохраняет
предыдущие файлы. Входные файлы защищены от совпадения с путями результата.
Два отдельных rename не являются единой транзакцией при сбое диска.
